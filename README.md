# 帰り道 — 短編3Dホラー

深夜2時、腹が減った会社員がコンビニへ行って、帰ってくる。それだけの話。

## 遊びかた

`kaerimichi.html` をブラウザで開くだけ。インストールも通信も不要（three.js だけ CDN から読み込みます）。

| 操作 | |
|---|---|
| W A S D ／ 矢印 | 移動 |
| マウス | 視点（画面をクリックするとマウスが固定されます） |
| Shift | さらに急ぐ |
| E | 調べる |
| Esc | 中断（音量・明るさ・感度を調整できます） |


### スマホ・タブレット

| 操作 | |
|---|---|
| 画面の左半分 | 移動（指を置いた場所にスティックが出ます。深く倒すと急ぎます） |
| 画面の右半分をなぞる | 視点 |
| 「調べる」ボタン／右半分を軽くタップ | 調べる |
| ☰ | 中断 |

横向きのほうが広く見えます。縦向きでも視野を自動で広げるので遊べます。

**ヘッドホン推奨。部屋は暗いほうがいいです。** 想定プレイ時間は8〜12分。

## 構成

道は一本道です。行きと帰りで必ず同じ景色を通ります。

```
アパート(101号室) ─ ゴミ捨て場 ─ 自動販売機 ─ 公園 ─ 曲がり角 ─ コンビニ
      z=0            z=-11        z=-46      z=-84    z=-124.5    x=-32
```

行きは何も起きません。帰り道から、さっき通った場所だけがおかしくなります。

## ファイル

| | |
|---|---|
| `kaerimichi.html` | 完成品。これ1つで動きます |
| `src/` | 分割ソース |
| `build.sh` | `src/` を1枚のHTMLに結合する（`./build.sh`） |

`src/` の中身:

| ファイル | 中身 |
|---|---|
| `00-head.html` | HTML骨格・CSS・UI |
| `10-tex.js` | テクスチャ生成（アスファルト、ブロック塀、トタン、瓦、畳…すべて canvas で描いています。画像ファイルは1枚もありません） |
| `20-snd.js` | 音の合成。虫の声も足音も「コンコン」も、その場で波形から作っています。音声ファイルも1つもありません |
| `30-core.js` | レンダラ、シーン、マテリアル、当たり判定、ライトプール |
| `40-world.js` | 夜の住宅街の建設 |
| `50-room.js` | 室内（同じ間取りから2部屋。片方は左右反転） |
| `60-player.js` | 移動・視点・UI |
| `65-touch.js` | スマホの操作（仮想スティック・視点ドラッグ・ボタン） |
| `70-story.js` | 進行と怪異 |
| `90-boot.js` | 起動とメインループ |

ソースを直したら `./build.sh` で `kaerimichi.html` を作り直してください。

## 技術メモ

- **ライトプール** — 街灯や自販機は「光源スペック」として登録しておき、毎フレーム近い順に実ライトへ貼り替えます。ライトの個数が変わらないのでシェーダの再コンパイルが起きず、光源をいくつ置いても重くなりません。
- **UVの実寸タイリング** — 箱を作るとき、面の実寸に合わせてUVを引き伸ばします。大きい壁でもテクスチャが間延びしません。
- **反転した部屋** — 最終盤の部屋は、同じ間取り生成関数に `mirror` を渡して x座標と y回転を反転させて建てています。負のスケールを使っていないので、法線も影も壊れません。時計とカレンダーの文字だけは、わざと鏡文字のテクスチャを使っています。
